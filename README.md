# Pharma Product & Cost Analysis

## Project Overview
An interactive Power BI dashboard for analyzing pharmaceutical products, pricing, locations, and associated costs.

## Key Analysis
- Analyzed pharmaceutical products, pricing, locations, and associated costs.
- Compared pack price and unit price across products and locations.
- Analyzed shipping and insurance costs to understand additional expenses.
- Developed interactive Power BI visuals for product and cost analysis.

## Tools & Technologies
- Power BI
- Data Analysis
- Data Visualization

## Dashboard
The dashboard provides interactive analysis of pharmaceutical product pricing and associated costs.
